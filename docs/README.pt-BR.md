# WorkOutRow — Triagem Logística Inteligente com IA

O **WorkOutRow** é um projeto de portfólio baseado em uma solução acadêmica colaborativa construída com **Microsoft Copilot Studio, Power Automate e SharePoint**.

O problema tratado é a transformação de solicitações logísticas escritas em linguagem natural em informações estruturadas para triagem.

## Fluxo conceitual

`Usuário → Copilot Studio → Power Automate → SharePoint`

A IA é utilizada para interpretar o relato, sugerir uma categoria, produzir um resumo factual e identificar ambiguidade. Dados operacionais não devem ser inventados pela IA.

## Categorias

- Rastreamento
- Coleta
- Documentação
- Reclamação
- Triagem Humana

## Evidências incluídas

O repositório apresenta capturas reais do ambiente do projeto:
- agente WorkOutRow no Copilot Studio;
- ferramentas e lógica conversacional;
- fluxos do Power Automate;
- tratamento de erro;
- registros no SharePoint;
- histórico de execuções;
- fluxos auxiliares.

## Limitação registrada

A classificação com IA foi configurada, porém sua validação completa por execução não foi concluída porque o ambiente ficou sem créditos. Por isso, a funcionalidade é apresentada como **implementada, mas com validação pendente por limitação do ambiente**.

## Autoria

O projeto acadêmico original foi desenvolvido de forma colaborativa. Este repositório não lista nomes de outros responsáveis nem atribui individualmente artefatos colaborativos. Ele apresenta a solução como estudo de caso técnico de portfólio.
